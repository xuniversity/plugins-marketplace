# 表单与详情分节标题样式规范

## 目标

统一表单和详情页的小标题视觉，避免同一业务中出现多套分节样式。

## 表单分节标题

- 用较轻的分隔线和稳定间距建立结构。
- 标题颜色使用 `hsl(var(--foreground))`。
- 辅助说明使用 `hsl(var(--muted-foreground))`。
- 不用硬编码颜色或固定 `px` 圆角。

## 详情分节标题

推荐样式：

```css
.detail-section-title {
  display: flex;
  align-items: center;
  gap: 8px;
  margin-bottom: 16px;
  padding-bottom: 12px;
  font-size: 15px;
  font-weight: 600;
  color: hsl(var(--foreground));
  border-bottom: 1px solid hsl(var(--border));
}

.detail-section-title::before {
  content: '';
  width: 3px;
  height: 16px;
  background: hsl(var(--primary));
  border-radius: var(--radius-sm);
}
```
